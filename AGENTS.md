# Codex Instructions

Ты работаешь над локальным помощником для покупок операторской техники в Китае.

## Главная задача
Создать приложение/CLI на Node.js + TypeScript + Playwright, которое запускает обычный видимый браузер, позволяет владельцу самостоятельно авторизоваться в Taobao/Tmall, а затем помогает собрать оптимальную корзину техники.

## Безопасность
- Никогда не проси пароль Taobao в терминале или конфиге.
- Авторизация выполняется человеком в открытом браузере.
- Не коммить browser profile, cookies, storage state, токены и персональные данные.
- Добавь их в `.gitignore`.
- Не обходи CAPTCHA и антибот-защиту.
- Не нажимай финальную оплату и не подтверждай заказ.
- Добавление в корзину должно происходить только после явного подтверждения пользователя.

## UX
Нужен простой запуск на macOS:
`npm install`
`npm run setup`
`npm run shop`

Первый запуск открывает Chrome и предлагает пользователю войти в Taobao. Сессия хранится только локально в игнорируемой директории `.browser-profile/`.

## Сбор данных
Для результатов поиска извлекай, когда это доступно:
- название;
- URL;
- магазин;
- текущую цену;
- цену после купона;
- продажи/число покупателей;
- Tmall/official badges;
- признаки из китайского текста;
- региональную версию;
- состояние;
- гарантию.

Не полагайся на один CSS selector: Taobao меняет DOM. Вынеси селекторы/эвристики отдельно, логируй понятную ошибку и сохраняй screenshot/debug HTML локально при сбое.

## Скоринг
Положительные признаки: `官方旗舰店`, `官方直营`, `天猫`, `正品行货`, `正规发票`, `全国联保`, `联保`.

Риски: `港版`, `港货` — допустимы, но требуют дисконта и явного предупреждения.

Сильные негативные признаки: `二手`, `以旧换新`, `回收`, `租赁`.

Подозрительно низкая цена относительно медианы результатов должна автоматически получать risk flag.

## Бюджет
Техника: 100 000 ₽ максимум.
Рюкзак: отдельный бюджет, target 7 000 ₽, hard max 10 000 ₽.

Курс CNY/RUB хранить в конфиге и разрешить менять при запуске.

## Выход
Создавай `output/results.json`, `output/cart.csv` и читаемый `output/report.md`.

Сформируй две корзины: `safe` и `value`.

Не добавляй товар, если не удалось уверенно определить точную модель/вариант. Для Tamron проверять `70-180`, `G2`, `A065`, `Sony E` и наличие VC. Не путать с первым поколением.

## Сравнение с Москвой
Архитектура должна позволять подмешивать российские цены вручную или через отдельный provider. Результат для каждой позиции: `BUY_CHINA`, `BUY_RUSSIA`, `SKIP`, плюс экономия в ₽.

Начни с MVP, который надежно открывает Taobao, сохраняет локальную сессию, выполняет поиск и экспортирует видимые карточки. Только после этого добавляй скоринг и работу с корзиной.
